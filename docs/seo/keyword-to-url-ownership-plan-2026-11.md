# PainFix SEO Keyword-to-URL Ownership Plan

**Status:** Proposal for review only — no production SEO changes authorised  
**Prepared:** 11 November 2026  
**Source:** User-supplied SEMrush Keyword Magic exports and consolidated keyword list, plus Pakistan-filtered Google Search Console data (12 Oct–10 Nov 2026).

## 1. Rules

1. This is a keyword-to-URL map, not a keyword redirect plan. Google ranks pages for queries; keywords themselves cannot be redirected.
2. Assign one preferred URL to each coherent intent cluster. Use natural headings, copy, FAQs and internal links; do not repeat exact-match phrases unnaturally.
3. Keep informational articles when they satisfy a distinct informational intent. Link them to relevant condition/service pages. Do not redirect blogs merely because they mention the same condition.
4. Do not create, redirect, canonicalise, delete or noindex a URL solely on the basis of this document.
5. Keep unsupported/irrelevant SEMrush suggestions out of target copy (for example generic “Multan price list”, “Multan Pakistan”, and competitor brand “Multan Physiocare”).
6. Pakistan-wide SEMrush volumes are not Multan search volumes. Treat them as relative discovery estimates, not local demand.
7. Any new disease-specific landing page requires confirmation that PainFix actually provides that service and a separate content/clinical review.
